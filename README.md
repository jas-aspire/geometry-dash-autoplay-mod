# jas.autoplayer

A lightweight **Geometry Dash Geode mod** that automates playing through uncompleted levels.

## ✨ Features

* **Level Browser** — automatically plays uncompleted levels on the current page.
* **Main Levels** — automatically works through Main Levels 1–22.
* **Map Packs** — automatic playback *(currently broken)*.
* **Gauntlets** — automatic playback *(currently broken)*.
* **Configurable Delay** — set the delay between levels from **0.5–20 seconds** in Geode settings.
* **Easy Stop** — press **F5** or tap the **AUTO** button to stop.

## 📥 Installation

This mod is **not currently available through the Geode Index**, so it must be installed manually.

1. Download the mod's `.dll` file.
2. Open your Geometry Dash installation folder.
3. Navigate to:

   ```text
   Geometry Dash\geode\mods
   ```
4. Drag the `.dll` file into the `mods` folder.
5. Launch Geometry Dash.
6. The mod should load automatically through Geode.

Your folder should look roughly like:

```text
Geometry Dash/
└── geode/
    └── mods/
        └── jas.autoplayer.dll
```

## ⚙️ How It Works

The mod builds a queue of uncompleted levels, loads each level, plays it, and automatically moves to the next one after completion.

Completed levels are skipped automatically.
